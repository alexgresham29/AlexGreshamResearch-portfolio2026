R Programming & Data Analysis

Statistical computing, data visualization, and reproducible research using R

Overview

Throughout the Summer 2026 intensive program, I developed proficiency in R as a primary tool for data analysis and scientific visualization. All work was conducted in RStudio using the R Markdown notebook format, which integrates executable code, output, and narrative text into a single reproducible document.

The analyses below progress from foundational statistical computing with base R to advanced data manipulation using the tidyverse ecosystem and biological data analysis with domain-specific packages such as Growthcurver. Each notebook link opens the fully rendered HTML output, including all code, figures, and interpretations.

Assignment 1

Introductory Data Analysis: Dog Weight Statistics

Complete

Objective

This assignment introduced core R programming concepts including data import, base graphics, statistical filtering with dplyr, and hypothesis testing. The dataset comprised weight measurements (in pounds) for three dog breeds: pitbulls, beagles, and dalmatians.

Methods & Skills Demonstrated

Data were imported from a comma-separated values (CSV) file using read.csv(). A multi-group boxplot was constructed using base R graphics to compare weight distributions across breeds. The distribution of pitbull weights was visualized both as raw measurements and as standardized Z-scores using histograms rendered in a two-panel layout with par(mfrow).

Statistical hypothesis testing was performed using the Student's t-test. A one-sample t-test was applied to evaluate whether beagle weight differed significantly from a reference value of 21 lbs (μ0 = 21). A two-sample t-test was used to compare pitbull and dalmatian weights, assessing whether the observed difference in means was statistically significant.

Assignment 2

Exploring Human Health Data with ggplot2 and dplyr

Complete

Objective

This assignment provided structured practice with the tidyverse ecosystem for data manipulation and visualization. A dataset of 200 simulated human samples was analyzed, containing physical measurements (height, weight) and clinical laboratory values (fasting blood glucose, LDL cholesterol), along with demographic variables (sex, hair color, eye color).

Data Manipulation with dplyr

The dplyr package was used extensively for data wrangling. select() was used to subset columns of clinical interest; filter() was applied to isolate samples meeting specific clinical criteria, such as female subjects with blood glucose exceeding 100 mg/dL (pre-diabetic range). mutate() was used to compute derived variables: body mass index (BMI) was calculated from height and weight, and a categorical glucose classification variable was created using case_when() to label samples as Normal, Pre-diabetic, or Diabetic. Summary statistics were generated with group_by() and summarise(), enabling sex-stratified and hair-color-stratified comparisons.

Data Visualization with ggplot2

Six figures were produced using the ggplot2 grammar of graphics framework, each demonstrating a distinct visualization technique:

Histogram (blood glucose by sex): An overlapping histogram with transparency (alpha = 0.6) illustrating the distribution of fasting glucose values across male and female participants.

Scatter plot with linear regression (height vs. weight): A scatter plot with sex-colored points and per-group regression lines generated using geom_smooth(method = "lm"), demonstrating the positive correlation between height and body mass in both sexes.

Box plot with jitter (BMI by sex): Distribution of BMI values overlaid with individual data points to reveal within-group variability and potential outliers.

Grouped bar chart (sample counts by hair color and sex): A dodged bar chart using geom_bar(position = "dodge") illustrating sample composition across demographic categories.

Scatter plot with colorblind-friendly palette (BMI vs. LDL): Points colored by glucose category using scale_color_brewer(palette = "Set2") to assess the relationship between adiposity and cholesterol across metabolic subgroups.

Faceted scatter plot (glucose vs. LDL by sex): facet_wrap(~ sex) used to produce side-by-side panels enabling direct visual comparison between male and female participants.

Conclusions

The analysis demonstrated that BMI was elevated in pre-diabetic and diabetic groups relative to normoglycemic individuals, consistent with the well-established association between obesity and impaired glucose regulation. However, substantial overlap between BMI distributions across glucose categories indicates that BMI alone is insufficient as a diagnostic predictor of glucose dysregulation. No strong linear relationship was observed between BMI and LDL cholesterol in this simulated dataset.

Assignment 3

Growth Curve Analysis Using the Tecan 96-Well Plate Reader

Complete

Objective

This analysis followed a bioinformatics vignette developed by the Gresham Laboratory to process and interpret optical density (OD600) growth curve data generated from a Tecan 96-well plate reader. The dataset comprised 283 time-series OD measurements acquired over 24 hours from four experimental conditions: Saccharomyces cerevisiae and Candida albicans grown in rich (YPD) and glutamine-limited media, with six biological replicates and three technical replicates per condition.

Analytical Workflow

Raw OD data were imported from CSV format and joined with a sample sheet mapping well identifiers to experimental conditions. Time values were converted from seconds to hours. Visual inspection of blank wells revealed contamination in two wells (D1 and D6), which were excluded from downstream analysis.

The Growthcurver package was used to fit each growth profile to a four-parameter logistic model:

N(t) = K / (1 + ((K − N⊂0;) / N⊂0;) · e−rt)

Model fitting yielded the following growth parameters for each well: growth rate (r, hr−1), carrying capacity (K, OD units), initial population size (N0), generation time (tgen), time to half-maximal carrying capacity (tmid), and area under the fitted logistic curve (AUC). Pairwise correlations among these parameters were visualized to assess parameter interdependence.

Results & Biological Interpretation

Growth rate: S. cerevisiae exhibited a higher growth rate in YPD than in glutamine-limited media, and grew faster than C. albicans under both conditions, consistent with its adaptation as a laboratory model organism.

Carrying capacity: Final OD values were similar between species in YPD, but diverged under glutamine limitation, suggesting differential sensitivity to nitrogen source availability.

Generation time: Generation times were shortest for S. cerevisiae in YPD, reflecting optimal growth under non-limiting nutrient conditions.

Parameter correlations: AUC and carrying capacity were highly correlated, as expected mathematically, while initial population size (N0) and tmid were largely independent of each other.

Assignment 4

Flow Cytometry Data Analysis: mCitrine Expression in S. cerevisiae

Complete

Objective

This analysis follows the Gresham Lab CytoExploreR vignette to process and interpret Cytek Aurora flow cytometry summary statistics. Four yeast strains were evaluated for mCitrine fluorescence on June 9, 2026, with the goal of quantifying the fraction of cells expressing the fluorescent reporter and interpreting the biological significance of expression heterogeneity.

Data & Pipeline

Gated summary statistics were exported from the Cytek Aurora in CSV format (20,000 events per sample). The full class dataset (June9_Scer_students.CSV) contained 17 samples; this analysis focuses on rows 14–17 (the "AG" samples). The CytoExploreR gating hierarchy applied was: All Events → Cells → FSC Singlets → mCitrine gate, using forward scatter (FSC-A) and the B2-A fluorescence channel.

Methods & Skills Demonstrated

The CSV was loaded with read_csv() and filtered to the AG rows using str_ends() and filter(). Column names containing spaces and special characters were handled with backtick quoting. Strain identifiers were extracted from sample name strings using str_extract() with a regular expression. Visualizations were produced with ggplot2, including a bar chart of mCitrine% per strain and a full-class comparison using coord_flip() and reorder(). Numeric formatting used scales::comma and formatC().
